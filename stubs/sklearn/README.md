# sklearn stubs

## Overview

Type stubs for the parts of scikit-learn this package calls, because scikit-learn ships no complete types.

## Components

| Component | Description |
|-----------|-------------|
| [base.pyi](./base.pyi) | `clone`. |
| [covariance.pyi](./covariance.pyi) | `LedoitWolf`. |
| [ensemble.pyi](./ensemble.pyi) | `IsolationForest`, `RandomForestClassifier`, and `HistGradientBoostingClassifier`. |
| [linear_model.pyi](./linear_model.pyi) | `LogisticRegression`. |
| [mixture.pyi](./mixture.pyi) | `GaussianMixture`. |
| [neighbors.pyi](./neighbors.pyi) | `LocalOutlierFactor` and `NearestNeighbors`. |
| [svm.pyi](./svm.pyi) | `OneClassSVM`. |
| [exceptions/](./exceptions/README.md) | `NotFittedError`. |
